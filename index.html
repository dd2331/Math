ALGEBRA 2 · POLYNOMIAL FUNCTIONS PROJECT

Which square should we cut to build the biggest shoe tray?

One A4 sheet. Four equal corner squares. One cubic polynomial that tells us exactly how big to cut. This site walks through the whole design, from the client brief to the final prototype.

Presented by StrideCraft Footwear Co.  ·  Team: Chaitanya, Elias, Zaid, Jan, Jad

Why are we doing this?

The client brief, the question and what we need to prove.

“We ship our sneakers in open-top trays made by cutting equal squares from each corner of an A4 sheet and folding up the sides. We want the tray with the largest possible volume. Tell us exactly what size squares to cut, prove it is the best choice, and send us a working prototype.”

The real-world problem

Shoe companies pay for material, shipping space and storage. A tray that holds more sneakers from the same sheet of cardboard saves money on every single shipment. But cutting a bigger square makes the walls taller and the base smaller, so it is not obvious where the best answer is.

What we need to do

  • Build real test boxes and look for a pattern.
  • Turn the pattern into a polynomial function V(x).
  • Find a sensible domain, and describe degree, end behavior and zeros.
  • Use a graph to find the maximum volume.
  • Build the best box and compare it to the model (percent error).
  • Explain why the math answer may need adjusting in the real world.

Driving question: how can a polynomial model help a company make the best design decision?

Part 2: building the model

From the flat sheet to a polynomial.

1 · Dimensions in terms of x

Cutting an x × x square from each corner of a 29.7 cm × 21 cm sheet uses x on each end of both sides.

Length = 29.7 − 2x
Width = 21 − 2x
Height = x

2 · Factored form

V(x) = x(29.7 − 2x)(21 − 2x)

3 · Standard form

(29.7 − 2x)(21 − 2x) = 623.7 − 59.4x − 42x + 4x² = 4x² − 101.4x + 623.7
V(x) = 4x³ − 101.4x² + 623.7x

4 · Check the model

V(3) = 4(27) − 101.4(9) + 623.7(3)
= 108 − 912.6 + 1871.1 = 1066.5 cm³

This matches the box we measured for x = 3. A real box can differ slightly because of measuring error, tape and fold thickness.

5 · Domain

0 < x < 10.5
  • x > 0: if x = 0 nothing is cut, so there are no walls and the “box” is the flat sheet (volume 0).
  • x < 10.5: the width 21 − 2x must be positive. At x = 10.5 the two cuts use up the whole 21 cm side and the base has width 0.
  • The length condition x < 14.85 is weaker, so the width is what limits us.

6 · Features of V(x)

FeatureAnswer
Degree3 (cubic)
Leading coefficient4 (positive)
End behaviorx → −∞: V → −∞
x → +∞: V → +∞
Zerosx = 0, 10.5, 14.85
  • x = 0: no cut, flat sheet, volume 0.
  • x = 10.5: width becomes 0, so the box is a flat strip with volume 0.
  • x = 14.85: the length would be 0, but this is outside the domain (the width is already negative), so it means nothing for a real box.

Two boxes with 1000 cm³

Solving x(29.7 − 2x)(21 − 2x) = 1000 gives x ≈ 2.56 cm and x ≈ 5.71 cm.

There are two answers because the volume rises to the peak and then falls, so the line V = 1000 crosses the curve once on each side. (The third root, 17.08, is outside the domain.)

What the pattern shows

  • As x gets bigger the height goes up but the base gets smaller.
  • The volume rises, peaks, then falls. The best of our whole-number cuts was x = 4 cm (1128.4 cm³).
  • Because the volume increases to x = 4 and drops by x = 5, a value just above 4 could do even slightly better. The model says it is 4.04.
  • x cannot be 0 (nothing to fold) and cannot be 11 (the width would be 21 − 22 = −1 cm).

Challenge questions

Tap each one to see the working.

1 · Find the maximum by testing values (no max feature)

The volume increases up to 4.04 and decreases at 4.05, so the maximum to two decimal places is x = 4.04 cm, V ≈ 1128.50 cm³.

2 · Best cut for a square sheet of side s

For a square sheet, V(x) = x(s − 2x)². Write V = ¼ · (4x)(s − 2x)(s − 2x). The three factors add up to 4x + (s − 2x) + (s − 2x) = s, a constant. A product with a fixed sum is largest when the factors are equal (AM–GM), so 4x = s − 2x, which gives 6x = s:

x = s / 6

Check with calculus: V′ = (s − 2x)(s − 6x) = 0, so x = s/6 (x = s/2 gives zero volume), and V″ < 0 there, so it is a maximum. The maximum volume is 2s³/27.

Try it: sheet side s = cm –
3 · Closed box with a lid

Use a net with the base in the middle, four walls of height h and the lid attached to one wall. The 21 cm side gives 2h + 2w = 21, so w = 10.5 − h, and the length is 29.7 − 2h.

V(h) = h(29.7 − 2h)(10.5 − h) = 2h³ − 50.7h² + 311.85h

Since (10.5 − h) = ½(21 − 2h), this is exactly half of the open-box function. So the best cut is the same, h ≈ 4.04 cm, and the maximum volume is ≈ 564.25 cm³ (21.62 × 6.46 × 4.04 cm). The lid uses half the sheet, so it halves the volume.

4 · Lowest cost per cm³

Cost per tray = 0.5 AED (sheet) + 4 × 0.1 AED (tape) = 0.90 AED, whatever the cut size. So the cost per cm³ is 0.9 / V(x), which is lowest when V(x) is largest:

x ≈ 4.04 cm → 0.9 / 1128.50 ≈ 0.0008 AED per cm³
x = 1 cm → 0.9 / 526.3 ≈ 0.0017 AED per cm³
5 · Average rate of change (why the maximum is between 3 and 5)
On [3, 4]: (1128.4 − 1066.5) / 1 = +61.9 cm³ per cm
On [4, 5]: (1083.5 − 1128.4) / 1 = −44.9 cm³ per cm

The volume was increasing on [3, 4] and decreasing on [4, 5]. The rate of change switches from positive to negative, so the peak lies between these two intervals, close to x = 4. A straight-line estimate of where the slope crosses zero gives x ≈ 4.08, close to the true 4.04.

Recommendation to the client

What StrideCraft Footwear Co. advises.

Cut 4.04 cm squares → volume 1128.50 cm³ (about 1.13 L)
  • Function: V(x) = x(29.7 − 2x)(21 − 2x) = 4x³ − 101.4x² + 623.7x, domain 0 < x < 10.5.
  • Practical option: a 4 cm cut gives 1128.4 cm³, a difference of less than 0.01%, and is far easier to measure with a ruler.
  • Model check: our five test trays averaged 1.63% error against the predicted 1128.50 cm³, so the model is trustworthy.
  • Real-world limits: measuring and cutting errors, thickness of cardboard and tape, and rounded folds all make a real box a little different from the model.
  • Recommendation: a tray holds about 1.13 L from this sheet — enough for a pair of sneakers. A slightly larger or squarer sheet would increase capacity (best cut = s/6 for a square). A lid halves the volume, so use a separate lid sheet.
