1Context

Why are we doing this?

Every company that ships a product pays for material, storage and space. A box that holds more from the same sheet saves money on every single shipment.

We ship our product in open-top trays made by cutting equal squares from each corner of an A4 sheet and folding up the sides. We want the tray with the largest possible volume. Tell us exactly what size squares to cut, prove it is the best choice, and send us a working prototype.CLIENT BRIEF

The puzzle

Cutting a bigger square makes the walls taller, but it also makes the base smaller. Cut too little and the box is flat. Cut too much and there is no base left. Somewhere in the middle is the best box, and it is not obvious where.

Driving question

How can a polynomial model help a company make the best design decision?

3The model

From a flat sheet to a polynomial

Everything about the box depends on one number, the cut size x.

1

Dimensions in terms of x

Cutting an x × x square from every corner takes x off each end of both sides.

Length = 29.7 − 2x
Width = 21 − 2x
Height = x
2

Factored form

V(x) = x(29.7 − 2x)(21 − 2x)
3

Standard form

(29.7 − 2x)(21 − 2x) = 623.7 − 59.4x − 42x + 4x² = 4x² − 101.4x + 623.7
V(x) = 4x³ − 101.4x² + 623.7x
4

Check the model

V(3) = 4(27) − 101.4(9) + 623.7(3)
= 108 − 912.6 + 1871.1 = 1066.5 cm³

This matches the box we measured for x = 3. A real box can differ slightly because of measuring error, tape and fold thickness.

Domain

0 < x < 10.5
  • x > 0: if x = 0 nothing is cut, so there are no walls and the “box” is the flat sheet (volume 0).
  • x < 10.5: the width 21 − 2x must be positive. At x = 10.5 the two cuts use up the whole 21 cm side and the base has width 0.
  • The length condition x < 14.85 is weaker, so the width is what limits us.

Features of V(x)

FeatureAnswer
Degree3 (cubic)
Leading coefficient4 (positive)
End behaviorx → −∞: V → −∞
x → +∞: V → +∞
Zerosx = 0, 10.5, 14.85

What the zeros mean

  • x = 0: no cut, flat sheet, volume 0.
  • x = 10.5: width becomes 0, so the box is a flat strip with volume 0.
  • x = 14.85: the length would be 0, but it is outside the domain (the width is already negative), so it means nothing for a real box.

5Explore

Test box data

Each test box was built from A4 paper with a different cut size. The table is calculated from the box dimensions.

What the pattern shows

  • As x grows, the height goes up but the base gets smaller.
  • The volume rises, peaks, then falls. The best whole-number cut was x = 4 cm (1128.4 cm³).
  • The volume increases up to x = 4 and drops by x = 5, so a value just above 4 could do slightly better. The model says it is 4.04.
  • x cannot be 0 (nothing to fold) and cannot be 11 (the width would be 21 − 22 = −1 cm).

Challenge questions

1Find the maximum by testing values (no max feature)

The volume increases up to 4.04 and decreases at 4.05, so the maximum to two decimal places is x = 4.04 cm, V ≈ 1128.50 cm³.

2Best cut for a square sheet of side s

For a square sheet, V(x) = x(s − 2x)². Write V = ¼ · (4x)(s − 2x)(s − 2x). The three factors add up to 4x + (s − 2x) + (s − 2x) = s, which is constant. A product with a fixed sum is largest when the factors are equal (AM–GM), so 4x = s − 2x, which gives 6x = s.

x = s / 6    maximum volume = 2s³ / 27

3Lowest cost per cm³

Cost per tray = 0.5 AED (sheet) + 4 × 0.1 AED (tape) = 0.90 AED, whatever the cut size. So the cost per cm³ is 0.9 / V(x), which is lowest when V(x) is largest.

x ≈ 4.04 cm → 0.9 / 1128.50 ≈ 0.0008 AED per cm³
x = 1 cm → 0.9 / 526.3 ≈ 0.0017 AED per cm³
4Average rate of change: why the peak is between 3 and 5
On [3, 4]: (1128.4 − 1066.5) / 1 = +61.9 cm³ per cm
On [4, 5]: (1083.5 − 1128.4) / 1 = −44.9 cm³ per cm

The volume was increasing on [3, 4] and decreasing on [4, 5]. The rate of change switches from positive to negative, so the peak lies between the two intervals, close to x = 4. A straight-line estimate of where the rate crosses zero gives x ≈ 4.08, close to the true 4.04.

8Recommendation

Our recommendation to the client

Cut 4.04 cm squares. Volume: 1128.50 cm³ (about 1.13 L).
  • FunctionV(x) = x(29.7 − 2x)(21 − 2x) = 4x³ − 101.4x² + 623.7x, domain 0 < x < 10.5.
  • Practical optionA 4 cm cut gives 1128.4 cm³, less than 0.01% less, and is far easier to measure with a ruler.
  • Model checkOur five test trays averaged – error against the predicted 1128.50 cm³, so the model is trustworthy.
  • Real-world limitsMeasuring and cutting errors, the thickness of cardboard and tape, and rounded folds all make a real box a little different from the model.
  • RecommendationA tray from this sheet holds about 1.13 L. A squarer sheet would increase capacity, since the best cut for a square sheet is s/6.
